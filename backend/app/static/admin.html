数据管理

管理单词的音节拆分与构词法数据，编辑后实时生效

📦 知识库 word_knowledge.db
你编辑过的音节和构词数据都会保存在这里，数据越积累越丰富，可以复制给其他电脑使用
⬇ 备份到知识库
把软件主数据库中已有的音节拆分和构词数据，复制一份到知识库文件中。首次使用或数据更新后点一次。
⬆ 从知识库补全
导入新词书后，自动用知识库中已有的数据来补全缺失的音节和构词信息。不会覆盖已有数据。
💾 导出知识库
下载知识库文件，可以复制到其他电脑、发给朋友、或留作备份。支持 SQLite 和 JSON 两种格式。
